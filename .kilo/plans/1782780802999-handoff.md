## Goal of the overall change
One per-tenant credential/env store so concurrent users never bleed secrets via
`os.environ`. Agent `environment` tool + `use_google` + the human settings UI all
share a request-scoped, per-tenant overlay (`server/tenant_environment.py`).
Google OAuth creds are stored as a single sensitive var `GOOGLE_OAUTH_CREDENTIALS`
(authorized-user JSON, encrypted at rest) rather than a separate Google store.
